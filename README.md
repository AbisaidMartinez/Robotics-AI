# Robotics-AI

This repository contains a collection of scripts, algorithms, and tools developed across various final projects at **CINVESTAV Campus Saltillo**. The work spans multiple domains, including:

- 🤖 **Robotics simulation and control**
- 🧠 **Artificial Intelligence and machine learning**

Each project reflects hands-on experience with real-world challenges, combining theoretical knowledge with practical implementation. The repository is organized into modular folders, each containing code, documentation, and results relevant to its specific domain.

This space is intended to showcase my technical growth, problem-solving strategies, interdisciplinary engineering approach, and applied research.
